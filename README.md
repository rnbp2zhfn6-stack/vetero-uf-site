# VeteRo UF

Officiell webbplats för VeteRo UF, ett UF-företag i Ulricehamn som utvecklar och säljer en vetekudde.

## Webbplatsens filer

- `index.html` – startsida
- `product.html` – produktsida
- `site.css` – gemensam design och layout
- `js/vetero-storefront.js` – mobilmeny, scroll-effekter och bildvisning

Webbplatsen använder vanlig HTML, CSS och JavaScript.

## Beställning

Köpförfrågningar hanteras via e-post: [vetero.uf@gmail.com](mailto:vetero.uf@gmail.com).

## Publicering

Webbplatsen är avsedd för GitHub Pages. Den planerade domänen är https://veterouf.com. DNS hos Wix ändras först när GitHub Pages är aktiverat och den nya webbplatsen är testad.
